# コミットメッセージルール

## フォーマット

```
<type>: <subject>

[optional body]
[optional footer]
```

## Type一覧

| Type | 用途 |
|------|------|
| `feat` | 新機能追加 |
| `fix` | バグ修正 |
| `docs` | ドキュメント変更のみ |
| `test` | テスト追加・修正 |
| `refactor` | リファクタリング |
| `perf` | パフォーマンス改善 |
| `chore` | ビルド・設定変更 |
| `ci` | CI/CD関連 |
| `style` | コードスタイル修正 |
| `revert` | コミット取り消し |

## Subject ルール

- 日本語で記述
- 50文字以内推奨
- 命令形（「追加する」ではなく「追加」）
- 末尾にピリオドを付けない

## 例

```
feat: ディスク使用量の増加トレンド予測機能を実装

線形回帰を使用して、過去7日間のデータから
将来のディスク使用量を予測する機能を追加。

(v1.16.0)
```

```
fix: 通知履歴表示のフォーマットエラーを修正
```

```
feat!: 設定ファイル形式をYAMLからTOMLに変更

BREAKING CHANGE: settings.ymlはsettings.tomlに変更されました。
```

## リリース時

マージコミットにはバージョン情報を含める:
```
feat: 機能名を実装 (v1.16.0)
```
